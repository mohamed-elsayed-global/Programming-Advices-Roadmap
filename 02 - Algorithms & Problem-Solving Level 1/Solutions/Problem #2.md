## 🧠 Deep Problem Deconstruction & Engineering Vision

Every algorithm designed in this course directly reflects the 5 core functionalities of a computer system:

1️⃣ **Input Data:** Taking raw data in.  
2️⃣ **Store Data:** Retaining data/instructions in memory.  
3️⃣ **Process Data:** Converting raw inputs into structured information.  
4️⃣ **Output Information:** Presenting calculated results.  
5️⃣ **Control:** Coordinating and directing sequence and execution flow.

---

### 🔵 Problem #2: Read & Print Name

> **Problem Statement:**  
> Write a program to ask the user to enter his/her name and print it on screen.

#### 🎯 Deep Analysis & Creator’s Reflection:
* **The Creator's Intent:** I am instructing the computer to enter a receptive state (being ready and listening for keyboard input), allocate dynamic memory for data persistence, and retrieve that data for display.

#### ⚙️ Computer Functionality Mapping:
* 📥 **Input Data:** Computer waits and receives a string from the user via an input device (keyboard).
* 💾 **Store Data:** Computer allocates dynamic memory (variable) to keep the name saved for later reuse.
* ⚙️ **Process Data:** Variable allocation, memory retrieval, and text formatting.
* 📤 **Output Information:** Presents the dynamic string stored in memory onto the monitor screen.
* 🎮 **Control:** Ordered sequence: `Start` ==>> `Input` ==>> `Store` ==>> `Output` ==>> `End`.
