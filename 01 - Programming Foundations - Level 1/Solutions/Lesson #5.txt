1️⃣ Decimal to Hexadecimal Conversions

To convert a decimal number to hexadecimal, division by 16 repeatedly and keeping track of the remainders. The remainders from bottom to top (last remainder is the most significant digit).

Remembering the hex digit values: A=10, B=11, C=12, D=13, E=14, F=15.

First Group (469, 1513, 479)

469:
469 \ 16 = 29, remainder 5
29 \ 16 = 1, remainder 13 = D
1 \ 16 = 0, remainder 1
Result: 1D5(16)

1513:
1513 \ 16 = 94, remainder 9
94 \ 16 = 5, remainder 14 = E
5 \ 16 = 0, remainder 5
Result: 5E9(16)

479:
479 \ 16 = 29, remainder 15 = F
29 \ 16 = 1, remainder 13 = D
1 \ 16 = 0, remainder 1
Result: 1DF(16)

Second Group (4722, 7221, 256, 4444)

4722:
4722 \ 16 = 295, remainder 2
295 \ 16 = 18, remainder 7
18 \ 16 = 1, remainder 2
1 \ 16 = 0, remainder 1
Result: 1272(16)

7221:
7221 \ 16 = 451, remainder 5
451 \ 16 = 28, remainder 3
28 \ 16 = 1, remainder 12 = C
1 \ 16 = 0, remainder 1
Result: 1C35(16)

256:
256 \ 16 = 16, remainder 0
16 \ 16 = 1, remainder 0
1 \ 16 = 0, remainder 1
Result: 100(16)

4444:
4444 \ 16 = 277, remainder 12 = C
277 \ 16 = 17, remainder 5
17 \ 16 = 1, remainder 1
1 \ 16 = 0, remainder 1
Result: 115C(16)

2️⃣ Hexadecimal to Decimal Conversions

Expand each digit by multiplying it by its corresponding power of 16 (16^n):

First Group (1D5, 5E9, 1DF)

1D5(16):
(1 * 16^2) + (13 * 16^1) + (5 * 16^0)
= (1 * 256) + (13 * 16) + (5 * 1)
= 256 + 208 + 5 = 469(10)

5E9(16):
(5 * 16^2) + (14 * 16^1) + (9 * 16^0)
= (5 * 256) + (14 * 16) + (9 * 1)
= 1280 + 224 + 9 = 1513(10)

1DF(16):
(1 * 16^2) + (13 * 16^1) + (15 * 16^0)
= (1 * 256) + (13 * 16) + (15 * 1)
= 256 + 208 + 15 = 479(10)

Second Group (12A4, 1C35, 100, 115C)

12A4(16):
(1 * 16^3) + (2 * 16^2) + (10 * 16^1) + (4 * 16^0)$=
= (1 * 4096) + (2 * 256) + (10 * 16) + (4 * 1)
= 4096 + 512 + 160 + 4 = 4772(10)

1C35(16):
(1 * 16^3) + (12 * 16^2) + (3 * 16^1) + (5 * 16^0)
= (1 * 4096) + (12 * 256) + (3 * 16) + (5 * 1)
= 4096 + 3072 + 48 + 5 = 7221(10)

100(16):
(1 * 16^2) + (0 * 16^1) + (0 * 16^0)
= 256 + 0 + 0 = 256(10)

115C(16):
(1 * 16^3) + (1 * 16^2) + (5 * 16^1) + (12 * 16^0)
= (1 * 4096) + (1 * 256) + (5 * 16) + (12 * 1)
= 4096 + 256 + 80 + 12 = 4444(10)

3️⃣ Hexadecimal to Binary (4-Bit Nibble Mapping)

Replace every single hex digit with its 4-bit binary equivalent:

13B4(16):

1 = 0001₂
3 = 0011₂
B (11) = 1011₂
4 = 0100₂

Binary: 0001 0011 1011 0100 (or 0001001110110100₂)

A5(16):

A (10) = 1010₂
5 = 0101₂

Binary: 1010 0101 (or 10100101₂)
